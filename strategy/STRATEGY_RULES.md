# 当前提醒规则与账户登记

2026-09-11 更新。个股买卖阈值、RSI 周期和阈值、60% 个股额度、20% ETF 额度及20%现金底线保持当前配置。新增的是数据口径、可持续性买入限制和实际账户估值。

## 分红口径

实盘与回测共用 `dividend_grid/dividends.py`：以最近已完成年度分红的财年为基准，汇总该财年已实施现金分红；更新财年已有正分红实施公告时，用新方案替换基准财年的同周期分红。例如新中期分红替换旧中期分红，不与旧中期重复相加，也不把半年分红直接当作全年分红。估值口径从实施公告日生效，实际现金仍在除息后确认；回测同样按公告日生效，不使用未来信息。

- 明确不分配：保留零分红年度，不能跳过去继续用更早年度；已派的中期分红仍计入该财年。
- 取消方案：该年度分红待复核，暂停依赖股息率的交易信号。
- 没有记录：数据未知，不等于零分红；保留该股当前仓位及资金占用。
- 过期：FY Y 的记录最长使用到 Y+2 年9月30日，此后仍没有新完整年度记录则暂停该股信号。这是数据有效期规则，不是法定披露期限。
- 已标识特别分红：暂停信号，核实后可使用带日期的 `dividend_overrides.json` 覆盖。公开接口不保证识别全部特别分红，仍需核对公告。

使用缓存回测时会同时读取 `raw` 中的原始分红响应，以保留未派息及取消记录；数据指纹包括这些原始文件。只有旧的已实施事件、没有原始响应时，无法恢复遗漏的零分红公告，仍受此限制。

## 质量买入限制

`quality_rules.json` 新增 `veto_buy_on_coverage_risk` 与 `veto_buy_on_coverage_unknown`，当前均为 `true`。

- 派息率、现金覆盖或银行监管指标高风险：暂停新增买入，等待复核。
- 可持续性未知、抓取失败或使用 `--no-coverage` 跳过检查：同样暂停新增买入。
- 普通股息率卖出和已确认的 `exit_reasons` 清仓仍可执行；质量风险本身不自动触发清仓。
- 多年现金流与分红必须连续且匹配财年；缺记录不补零。五年覆盖正常但最新年度低于1倍时，提示趋势风险并暂停新增买入。
- 分红总额只纳入年度方案已实施或明确不分配的完整财年，中期分红不会单独充当全年分母。银行核心一级资本使用 `HXYJBCZL`；`FIRST_ADEQUACY_RATIO` 是一级资本，不能替代核心一级资本。
- 实盘不再用财年股息率反推 TTM 分红与 TTM 现金流配比；无法取得足够完整年度数据时显示未知。
- 中国平安等保险公司不使用一般企业 FCF 公式，默认待专项人工复核。需核查偿付能力、可分配利润和子公司向母公司分红能力。

经人工核实的结果可逐股登记在 `coverage_reviews` 中，包含 `flag`（`ok`、`warn`、`risk`）、`as_of`、`expires_on`、`reason`。例：

```json
{
  "coverage_reviews": {
    "待复核代码": {
      "flag": "warn",
      "as_of": "2026-09-11",
      "expires_on": "2026-10-31",
      "reason": "填写已核实报告、指标和判断依据"
    }
  }
}
```

此段应合并进现有质量配置；系统没有预填任何通过结论。复核过期后恢复自动检查结果。覆盖度复核不能绕过独立的派息率否决或基本面退出。

## 实际账户估值

两套提醒都会自动检测工作目录的 `account.json`；也可用 `--account-file` 指定。该文件已加入 Git 忽略。没有账户文件时继续使用旧 `holdings.json` 和 `rsi6_holdings.json`，提醒会标注手工仓位估算。

`account.example.json` 是含占位值的模板，不能作为真实账户直接运行。需要填写：

| 字段 | 含义 |
|---|---|
| `as_of` | 最近一次与实际账户核对的日期 |
| `cash` | 账户现金余额，元；不得用总资产代替 |
| `positions` | 股票代码到实际股数、ETF实际份额的映射，包含全部持仓 |
| `etf_layers` | 实际成交后对应的策略层数，0至10；与ETF份额的空仓状态须一致 |
| `external_assets` | 可选：清单外、仅估值持仓的代码到名称映射；数量仍填在 `positions` 中 |
| `etf_industry_weights` | 可选：ETF行业权重，使用和股票清单一致的行业名称；完整权重合计1 |

账户净值按现金加全部持仓市值计算。个股份数由实时市值占比换算；ETF层数只表示策略状态，不再当作实际资金占比。ETF减仓按实际份额比例估算，增配预算按目标市值与实际市值之差计算。

任一实际持仓缺价格、既不在清单也未登记为其他持仓，或字段仍是占位值时，停止账户估值，不回退为零持仓。成交、分红到账和送转后需更新登记；本工具不连接券商自动同步。现金不包含尚未到账的股息，应在实际到账后更新。

例如清单外ETF可登记为 `"external_assets": {"sh588000": "科创50ETF", "sz159915": "创业板ETF"}`。其他持仓计入总资产、现金比例及两套策略的资金占用，不生成网格或RSI买卖信号；512890的20%额度仍单独预留，因此其他持仓会减少个股可用额度。目前其他持仓尚未做行业穿透，报告会明确标注。

提供ETF行业权重时，其实际市值会占用相应行业额度；没有权重时明确提示未穿透。权重需来自已核实的基金披露并随持仓更新，本次没有编造或预填ETF成分。

```bash
uv run python scripts/grid_calculator.py --source akshare --stocks-file watchlist.json --account-file account.json --notify none
uv run python scripts/rsi6_calculator.py --account-file account.json --notify none
```

账户模式下不允许同时指定手工持仓覆盖。默认保留现金和行业限制均为新增买入限制，市值漂移不会自动触发强制再平衡。

## 回测边界

新版回测已接入带披露日期的历史现金流和银行监管指标，与实盘共用现金覆盖打标及买入限制。保险没有当时有效的人工复核则保持未知、暂停新增买入；没有历史ETF行业权重则不进行穿透。数据源提供的是现在可下载的历史报表，仍可能含重述，不是严格保存原始披露版本的历史数据库。
