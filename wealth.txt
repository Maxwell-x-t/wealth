# 📈 Investment OS（个人长期投资管理系统）

## 一、项目目标

打造一套适用于长期（20~30年）指数投资的个人投资管理系统。

支持：

- 中国大陆ETF/QDII
- 香港ETF（Trade25）
- 后续支持UCITS ETF
- 自动资产统计
- 自动收益分析
- 自动再平衡建议
- 自动投资计划
- 长期财富预测

系统定位：

> 长期资产配置系统（Investment OS）

而不是简单的记账软件。

---

前端：

Vue 3 + Vite + Pinia + Vue Router

UI：Naive UI（深色主题）

# 六、持仓统计

自动统计：

剩余总成本（按移动加权平均法扣减卖出成本后的持仓成本）

加权平均成本价（每股）

持仓数量

当前价格

当前市值

浮盈（未实现盈亏）

已实现盈亏（该品种累计）

收益率（浮盈 / 剩余总成本）

占总资产比例

## 成本核算与收益计算约定

### 成本法

采用移动加权平均成本法（非 FIFO）。

### 买入

新加权均价 = (原剩余总成本 + 本次买入金额) / 新总数量

本次买入金额 = 成交数量 × 成交价 + 手续费

### 卖出

卖出成本 = 卖出数量 × 卖出前加权均价

剩余总成本 = 原剩余总成本 − 卖出成本

剩余数量 = 原数量 − 卖出数量

剩余加权均价 = 剩余总成本 / 剩余数量（每股均价不变，除四舍五入）

已实现盈亏 = 卖出成交金额 − 卖出成本 − 手续费

### 全部卖出

该品种持仓数量归零，剩余总成本归零，已实现盈亏保留在历史记录中。

### 净投入（Dashboard「总投入」口径）

净投入 = 累计买入金额（含买入手续费）− 累计卖出回款（已扣除卖出手续费）

反映当前仍在投资中的资金规模。

### 总收益

总收益 = 当前持仓市值 + 累计卖出回款 − 累计买入金额（均含手续费）

### 收益率

收益率 = 总收益 / 净投入

净投入为 0 时（例如全部赎回），收益率不展示或单独标注。

### XIRR

基于现金流计算：买入为流出，卖出为流入，当前市值作为最后一笔虚拟流入。

与净投入展示口径配合，用于衡量年化回报。

# 十八、核心原则（Investment Policy Statement）

1. 长期投资20年以上
2. 不预测市场顶部和底部
3. 按计划定投
4. 不因短期涨跌停止投资
5. 每年最多再平衡一次
6. 优先使用新增资金再平衡
7. 保持纪律，避免情绪化交易
8. 提高收入和持续投入，比频繁择时更重要
