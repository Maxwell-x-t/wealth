# 📈 Investment OS（个人长期投资管理系统）

## 一、项目目标

打造一套适用于长期（20~30年）指数投资的个人投资管理系统。

支持：

- 中国大陆ETF/QDII
- 香港ETF（Trade25）
- 后续支持UCITS ETF
- 自动资产统计
- 自动收益分析
- 自动再平衡建议
- 自动投资计划
- 长期财富预测

系统定位：

> 长期资产配置系统（Investment OS）

而不是简单的记账软件。

自动统计：

剩余总成本（按移动加权平均法扣减卖出成本后的持仓成本）

加权平均成本价（每股）

持仓数量

当前价格

当前市值

浮盈（未实现盈亏）

已实现盈亏（该品种累计）

收益率（浮盈 / 剩余总成本）

占总资产比例

## 成本核算与收益计算约定

### 成本法

采用移动加权平均成本法（非 FIFO）。

### 买入

新加权均价 = (原剩余总成本 + 本次买入金额) / 新总数量

本次买入金额 = 成交数量 × 成交价 + 手续费

### 卖出

卖出成本 = 卖出数量 × 卖出前加权均价

剩余总成本 = 原剩余总成本 − 卖出成本

剩余数量 = 原数量 − 卖出数量

剩余加权均价 = 剩余总成本 / 剩余数量（每股均价不变，除四舍五入）

已实现盈亏 = 卖出成交金额 − 卖出成本 − 手续费

### 全部卖出

该品种持仓数量归零，剩余总成本归零，已实现盈亏保留在历史记录中。

### 净投入（Dashboard「总投入」口径）

净投入 = 累计买入金额（含买入手续费）− 累计卖出回款（已扣除卖出手续费）

反映当前仍在投资中的资金规模。

### 总收益

总收益 = 当前持仓市值 + 累计卖出回款 − 累计买入金额（均含手续费）

### 收益率

收益率 = 总收益 / 净投入

净投入为 0 时（例如全部赎回），收益率不展示或单独标注。

### XIRR

基于现金流计算：买入为流出，卖出为流入，当前市值作为最后一笔虚拟流入。

与净投入展示口径配合，用于衡量年化回报。

# 八、自动投资计划（已实现）

自动生成：

未来20年（跨度可配置）

所有投资计划。

包括：

建仓阶段

定投阶段

每月计划

每周计划

节假日可调整（提前至最近交易日）。

执行与匹配规则：

- 合并单元：账户 + 分类（大陆/香港 × 纳指/标普），不绑定具体代码
- 交易匹配：计划日 ±5 天；≥80% 或 ±20% 容差内视为完成
- 部分完成：窗口关闭后有买入但不足 80%，仅差额顺延到下一笔
- 完全未买：窗口关闭后全额合并到同组下一笔，展示应投 = 原计划 + 补投
- 窗口未关闭：计划日已过仍显示逾期，可补录，不提前合并
- 历史记录：建仓/定投的计划金额、实际投入、状态与定投执行率
- 一键录入：按账户+分类跳转交易页预填
- 大额买入：可从旧到新一次核销多周欠投
- 收益统计仍以真实交易为准，计划仅作执行指引

已实现（MVP，页面「财富预测」）：

- 起点：当前总资产、净投入
- 未来投入：投资计划应投金额（超出计划跨度时按定投月额×12）
- 公式：每年末资产 = (年初资产 + 当年投入) × (1 + 年化收益)
- 默认：悲观 4% / 中性 8% / 乐观 12%，年限 20（参数配置可改）
- 页面可临时改年限（5/10/15/20/30）与收益率试算
- 输出：三条资产曲线、累计本金、终点资产/本金/收益/收益率
- 可选勾选：通胀调整（实际购买力）、蒙特卡洛（P10/中位数/P90，均值=中性收益）
- 默认通胀 2%、MC 波动率 15%、路径 500（参数配置可改）

# 十八、核心原则（Investment Policy Statement）

1. 长期投资20年以上
2. 不预测市场顶部和底部
3. 按计划定投
4. 不因短期涨跌停止投资
5. 每年最多再平衡一次
6. 优先使用新增资金再平衡
7. 保持纪律，避免情绪化交易
8. 提高收入和持续投入，比频繁择时更重要
