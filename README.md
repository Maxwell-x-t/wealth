# Wealth Investment OS

个人长期指数投资管理系统。

## 技术栈

- 前端：Vue 3 + Vite + Naive UI + ECharts
- 后端：Python + FastAPI + SQLite
- 部署：本机运行

## 功能

### 阶段 1
- 交易记录（原币记账：CNY / USD）
- 移动加权平均成本、净投入口径收益统计
- 持仓与 Dashboard 总览
- 品种管理、手动行情更新

### 阶段 2
- 建仓 / 定投计划自动生成（节假日提前交易日）
- 投资计划页：进度、**历史记录**、逾期提醒、**部分完成 / 差额顺延**、**一键录入交易**
- 计划按**标的大类**（账户 × 纳指/标普），不绑定具体代码
- 资产配置目标：纳指 / 标普 / A股 / 黄金 / 现金 / QDII
- 账户分布目标：大陆 / 香港
- **汇率更新**：美元市值折算（快照 + 历史）
- 再平衡建议（指数 + 账户 + 品种）

## 投资计划说明

计划按「账户 + 分类」分组（如：大陆 · 纳指、香港 · 标普），不跨组合并，也不指定具体 ETF 代码。同组下任意品种的买入均可核销该计划。

### 计划状态

| 状态 | 含义 |
|------|------|
| 待执行 | 未来计划日 |
| 今日 | 计划日为今天 |
| 已完成 | 窗口内投入 ≥ 计划金额的 80%（或 ±20% 容差内） |
| 部分完成 | 窗口已关闭，有买入但不足 80%；差额并入下一笔 |
| 已合并 | 匹配窗口已关闭且完全未买，全额已并入下一笔 |
| 已逾期 | 计划日已过、窗口未关或无可合并的下一笔 |

### 交易匹配

- 在计划日 **±5 天**内查找同账户、同分类的**买入**交易
- 金额容差 **±20%**（含手续费）；≥ 80% 即视为完成
- 同一组内从**旧到新**核销；单笔大额买入可一次覆盖多周欠投

### 逾期与差额顺延（补投）

仅在匹配窗口关闭后（计划日 +5 天之后）才顺延：

| 情况 | 顺延金额 |
|------|----------|
| 完全没买 | 整笔计划金额 |
| 部分完成（如计划 8400、实投 5000） | 仅差额（3400） |
| 已完成（≥ 80%） | 无 |

窗口未关闭时，即使计划日已过也只显示「已逾期」，仍可补录，不提前合并。

下一笔展示 **应投金额** = 原计划 + 补投合计。

示例：计划 ¥8,400，只买了 ¥5,000 → 部分完成，下一期应投 = 下期原计划 + ¥3,400。

若计划期末尾没有后续待执行项，逾期项仍会保留在「逾期」页。

### 历史记录

投资计划页「历史记录」Tab 展示已到期的建仓 / 定投计划：

- 计划金额 / 实际投入 / 应投合计 / 状态
- 顶部「定投执行率」= 定投已完成笔数 / 已到期定投笔数

### 与收益统计的关系

- **持仓、净投入、XIRR**：只认真实交易日期与金额
- **投资计划**：执行指引；补录交易按成交日记账，与计划状态可不一致

## 汇率说明

| 用途 | 数据来源 |
|------|----------|
| 美元持仓市值折人民币 | 「汇率更新」最新快照（无则用参数配置默认值） |
| 交易净投入 / XIRR | 每笔交易填写的当日美元兑人民币 |

## 快速启动

```bash
chmod +x start.sh
./start.sh
```

- 前端：http://127.0.0.1:5173
- 后端：http://127.0.0.1:8000

## 建议使用流程

1. **参数配置** → 设置资产目标比例、建仓/定投参数
2. **汇率更新** → 更新当前美元汇率（用于市值折算）
3. **投资计划** → 查看应投金额（含补投），点击「录入」跳转交易
4. **交易记录** → 录入买卖（美元品种填美元价 + 当日汇率）
5. **行情更新** → 更新各 ETF 最新价
6. **总览** → 查看收益、仓位偏差、再平衡建议
