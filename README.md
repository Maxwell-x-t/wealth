# Wealth Investment OS

个人长期指数投资管理系统（Investment OS）。本机运行，中文界面。

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue 3 + Vite + Naive UI + ECharts |
| 后端 | Python + FastAPI + SQLite |
| 部署 | `./start.sh` 本机启动 |

## 功能现状

### 已完成 · 阶段 1（记账与总览）

- 交易记录：原币记账（CNY / USD），美元交易填当日汇率
- 成本法：移动加权平均（非 FIFO）
- 收益口径：净投入 = 累计买入（含手续费）− 累计卖出回款；含 XIRR
- 持仓、Dashboard 总览、品种管理
- 行情更新：一键拉取（大陆东方财富/新浪，美股新浪/Yahoo）+ 手动补录

### 已完成 · 阶段 2（计划与配置）

- 建仓 / 定投计划自动生成（节假日提前至最近交易日）
- 投资计划：历史记录、部分完成 / 差额顺延、一键录入交易
- 计划按**标的大类**（账户 × 纳指/标普），不绑定具体代码
- 资产配置目标：纳指 / 标普 / A股 / 黄金 / 现金 / QDII（合计 100%）
- 账户分布目标：大陆 / 香港（合计 100%）
- 汇率快照管理：一键拉取（新浪在岸/离岸）+ 手动补录
- 再平衡建议（指数 + 账户 + 品种，优先新增资金）

### 已完成 · 阶段 3

- **财富预测**：悲观 / 中性 / 乐观复利曲线；可勾选**通胀**（实际购买力）与**蒙特卡洛**（P10/中位数/P90）
- **风险模拟**：跌幅 30%/40%/50% 与历史熊市参考；恢复年限、终点资产
- **年度检查**：定投纪律 / 配置 / 应急资金清单，带系统提示
- **定时同步**：参数配置中开启后，后端按间隔自动拉取行情与汇率（可立即同步一次）

### 未做（后续）

- 税务模拟
- 券商 CSV / IBKR / Trade25 导入

完整产品规格见 [`wealth.txt`](wealth.txt)。

## 建议使用流程

1. **参数配置** → 资产/账户目标、建仓与定投金额、预测默认收益率
2. **汇率更新** → 一键拉取当前美元汇率（市值折算）
3. **投资计划** → 查看应投（含补投），点「录入」跳转交易
4. **交易记录** → 录入买卖（美元品种填美元价 + 当日汇率）
5. **行情更新** → 一键拉取各 ETF 最新价（失败可手动补）
6. **总览** → 收益、仓位偏差、再平衡建议
7. **财富预测** → 调整年限与收益率，看长期路径与风险回撤
8. **年度检查** → 年终勾选复盘项（可选）
9. **参数配置 · 定时同步** → 开启后自动拉行情/汇率（需后端常开）

## 投资计划说明

计划按「账户 + 分类」分组（如：大陆 · 纳指、香港 · 标普），不跨组合并，不指定具体 ETF 代码。同组下任意品种的买入均可核销该计划。

### 计划状态

| 状态 | 含义 |
|------|------|
| 待执行 | 未来计划日 |
| 今日 | 计划日为今天 |
| 已完成 | 窗口内投入 ≥ 计划金额的 80%（或 ±20% 容差内） |
| 部分完成 | 窗口已关闭，有买入但不足 80%；差额并入下一笔 |
| 已合并 | 匹配窗口已关闭且完全未买，全额已并入下一笔 |
| 已逾期 | 计划日已过、窗口未关，或无可合并的下一笔 |

### 交易匹配

- 在计划日 **±5 天**内查找同账户、同分类的**买入**交易
- 金额容差 **±20%**（含手续费）；≥ 80% 即视为完成
- 同一组内从**旧到新**核销；单笔大额买入可一次覆盖多周欠投

### 逾期与差额顺延（补投）

仅在匹配窗口关闭后（计划日 +5 天之后）才顺延：

| 情况 | 顺延金额 |
|------|----------|
| 完全没买 | 整笔计划金额 |
| 部分完成（如计划 8400、实投 5000） | 仅差额（3400） |
| 已完成（≥ 80%） | 无 |

窗口未关闭时，即使计划日已过也只显示「已逾期」，仍可补录，不提前合并。

下一笔 **应投金额** = 原计划 + 补投合计。

### 历史记录

「历史记录」Tab 展示已到期的建仓 / 定投：计划金额、实际投入、应投合计、状态。

顶部「定投执行率」= 定投已完成笔数 / 已到期定投笔数。

### 与收益统计的关系

| 模块 | 口径 |
|------|------|
| 持仓 / 净投入 / XIRR | 只认真实交易日期与金额 |
| 投资计划 | 执行指引；补录按成交日记账，可与计划状态不一致 |

## 财富预测说明

| 项 | 规则 |
|----|------|
| 起点 | 当前总资产、净投入 |
| 未来投入 | 投资计划应投金额；超出计划跨度时按「定投月额 × 12」 |
| 公式 | 每年末资产 = (年初资产 + 当年投入) × (1 + 年化收益) |
| 情景 | 悲观 / 中性 / 乐观（确定性复利；可另开蒙特卡洛） |
| 输出 | 资产曲线、累计本金、终点资产 / 本金 / 收益 / 收益率 |

页面可临时改年限与收益率；「参数配置」中的值为默认。

风险模拟假设资产立刻下跌，之后按**中性年化**继续定投，计算回到崩盘前资产所需年数，以及预测期末资产。

可选增强（页面勾选）：

| 选项 | 作用 |
|------|------|
| 通胀调整 | 按年通胀把名义金额折成今天购买力（默认 2%） |
| 蒙特卡洛 | 以中性收益为均值、可调波动率，模拟多条路径，展示较差 10% / 中位数 / 较好 10% |

两者可同时开启：蒙特卡洛区间也会按通胀折算。

## 定时同步

在「参数配置」中开启，设置间隔小时数并保存。后端进程需保持运行；也可用「立即同步行情+汇率」。默认关闭。

## 汇率与记账

| 用途 | 数据来源 |
|------|----------|
| 美元持仓市值折人民币 | 「汇率更新」最新快照（无则用参数配置默认值） |
| 交易净投入 / XIRR | 每笔交易填写的当日美元兑人民币 |
| 大陆品种 | CNY 记账 |
| 香港品种 | USD 记账 |

汇率一键拉取：优先新浪**在岸**人民币（`USD/CNY`），失败回退**离岸**；同时写入快照与参数配置默认值。

## 快速启动

```bash
chmod +x start.sh
./start.sh
```

- 前端：http://127.0.0.1:5173
- 后端：http://127.0.0.1:8000
- API 文档：http://127.0.0.1:8000/docs

首次启动会创建虚拟环境、安装依赖，并初始化 SQLite（`backend/data/`，已 gitignore）。

## 行情与汇率数据源

| 类型 | 主源 | 备用 |
|------|------|------|
| 大陆 ETF（数字代码） | 东方财富 | 新浪财经 |
| 美股 ETF（如 QQQM、VOO） | 新浪美股 | Yahoo Finance |
| 美元兑人民币 | 新浪在岸 | 新浪离岸 |

依赖外网；拉取失败时保留手动更新。非交易时段可能为最近收盘价。
